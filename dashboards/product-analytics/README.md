# LeoAnalyst — продуктовая аналитика Pulse Studio v2

**Статус:** демонстрационная версия на согласование. Основной сайт LeoAnalyst не менялся.

## Просмотр

Быстрый способ: дважды кликните `LeoAnalyst_Product_Analytics_Demo_v2.html` (лежит отдельно от архива).

Для размещения на GitHub Pages загрузите **всю** папку `dashboards/product-analytics/` в ваш репозиторий.
Адрес после загрузки:
`https://leonidbaliakin.github.io/LeoAnalyst/dashboards/product-analytics/`

## Структура проекта

- `index.html` — самостоятельная HTML-страница дашборда.
- `style.css` — базовая сетка и компоненты.
- `studio.css` — **новый дизайн**: палитра, типографика, карточки, адаптивность (лучшее место для визуальных правок).
- `app.js` — вкладки, расчёты, графики, фильтры, модальные окна, перевод, экспорт.
- `data.js` — воспроизводимые вымышленные пользователи/события/покупки.

## Что работает

8 разделов: обзор, аудитория, удержание, воронки, монетизация, когорты, события, выводы.
Выбор периодов, платформ, стран, каналов, тарифов; RU/EN, ₽/$; светлая/тёмная тема; отдельные карточки показателей; подсказки на графиках; кликабельная матрица D0/D1/D3/D7/D14/D30/D60; модальные окна; выгрузка CSV.

Темы переключаются **только** кнопкой с луной/солнцем вверху справа. Фильтры тему не изменяют.

## Формулы и ограничения

Все данные **демонстрационные** и синтетические. Это интерактивный образец, а не готовое подключение к реальной базе.
- DAU/WAU/MAU: уникальные пользователи за 1/7/30 дней, заканчивающихся выбранной датой.
- D1/D7/D30: возврат точно в соответствующий день, только зрелые когорты.
- ARPU: выручка за выбранный период / активные пользователи за выбранный период.
- LTV: накопленная выручка / количество зарегистрированных пользователей выбранного сегмента (историческая оценка, не прогноз).
- Валюты пересчитываются по **фиксированному учебному курсу 86,4 ₽ за $1**, не биржевой курс.
- CSV содержит данные демонстрационного набора (для платежей — суммы в исходных USD).

Изменения фильтров и выбранной страницы не отправляются на сервер. Для постоянных данных или многопользовательского режима нужен отдельный сервер.

## Как менять

1. Цвета, размеры, фон: `studio.css`.
2. Метрики, обработчики, страницы, перевод: `app.js`.
3. Выборку и случайные события: `data.js`.
4. Основной `index.html` сайта пока не трогаем. После утверждения можно подключить дашборд как полноэкранную модалку через `iframe` из папки `/dashboards/product-analytics/`.
